# echo-experience
Toothed whale echolocation content for experiential exhibits

## Licensing
All code and documentation is issued under the MIT license. Content is licensed via the Orcasound Creative Commons license (CC-BY-SA-NC) with attribution to "Orcasound" ideally with a link back to https://orcasound.net

## Motivation

The goal of this repository is to provide underwater audio recordings of echolocation to support development of exhibits that educate listeners/visitors about how toothed whales use sound to navigate and hunt. The intent is for the cotent to be open access, clearly-licensed, and free for non-commercial use. Commercial users should seek permission via info@orcasound.net

The initial use of this repository is an echolocation experience at [The Whale in Andenes, Norway](https://thewhale.no).
